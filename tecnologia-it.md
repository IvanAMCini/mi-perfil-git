# Contenedores con Docker

## ¿Qué tecnología es?
Docker permite empaquetar una aplicación y sus dependencias en una imagen.
Un contenedor es una instancia de esa imagen en ejecución, con aislamiento
de procesos y recursos. Los contenedores comparten el núcleo del sistema anfitrión.

## ¿Por qué me interesa?
Quiero aprender a ejecutar un proyecto con un entorno consistente para facilitar
las prácticas en equipo y reducir problemas por diferencias de configuración.
